# Recovery: after a restart or a crash

Use this after the Mac restarts, the app crashes, or a session stops responding.

1. **Check the models.** Open each session's settings and compare its model and effort with `docs/MODELS.md`. Crashes can reset them.
2. **Check Remote Control.** If you use it, turn it on again for each session you want on your phone.
3. **Check scheduled runs.** On the Scheduled page, look for a run that has been "Running" for much longer than usual. A frozen run blocks the schedule. Stop that run, and the next one will start on time.
4. **Check hung sessions.** A session that has stopped responding: press Esc (or the stop button). Then send it `/pickup <Role>`. It resumes from its pick-up note in `docs/pickup/`.
5. **Tell Manager** what you found, in one line. Manager records it on the board.
